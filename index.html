Frontend Dictionary

  1. Block-level - content that participates in block-level content (in CSS).
  2. Global attributes - attributes that are common to all HTML elements. they can be used on all elements, though they may have no effect on some elements.
  3. Cascading Style Sheets (CSS) - a stylesheet language used to describe the presentation of a document written in HTML or XML (including XML dialects such as SVG, MathML or XHTML).
  4. JavaScript (JS) - a lightweight interpreted (or just-in-time compiled) programming language with first-class functions.
  5. Internet - a worldwide network of networks that uses the Internet protocol suite (also named TCP/IP from its two most important protocols). https://developer.mozilla.org/en-US/docs/Glossary/Internet
  6. h1 to h6 - elements that represent six levels of section headings. By default, all heading elements create a block-level box in the layout.
  7. Hypertext - link that connect web pages to one another, either within a single website or between websites.
  8. HyperText Markup Language (HTML) - formatting language for displaying content over Internet. https://www.britannica.com/technology/HTML
  9. link - HTML element that specifies relationships between the current document and an external resource. Most commonly used to link stylesheets, but is also used to establish site icons (both favicon style icons and icons for th home screen and apps on mobile device) among other things.
  10. media - attribute of link that specifies media type or allow to add query inside, This resource will then only be loaded if the media condition is true.
  11. preliad - link attribute which indicates that the browser should preload this resource, together with as attribute indicating the specific class of content being fetched (new performance and security enhancement)
  12. rel - link element attribute that stands for relationship, and is one of the key features of link element, rel value denotes how the item being linked to is related to the containing document. Could be also used to indicate icon types.
