Definitions

  1. Block-level box
    - content that participates in block-level content (in CSS).
  2. Global attributes
    - attributes that are common to all HTML elements. they can be used on all elements, though they may have no effect on some elements.
  3. Cascading Style Sheets (CSS)
    - a stylesheet language used to describe the presentation of a document written in HTML or XML (including XML dialects such as SVG, MathML or XHTML).
  4. clearTimeout
    - method of the Window interface cancels a timeout previously established by calling Window.setTimeout(). If the parameter provided does not identify a previously established action, this method does nothing.
  5. JavaScript (JS)
    - a lightweight interpreted (or just-in-time compiled) programming language with first-class functions.
  6. Internet
    - a worldwide network of networks that uses the Internet protocol suite (also named TCP/IP from its two most important protocols). https://developer.mozilla.org/en-US/docs/Glossary/Internet
  7. h1 to h6
    - elements that represent six levels of section headings. By default, all heading elements create a block-level box in the layout.
  8. head
    - element contains machine-readable information (metadata) about the document, like its title, scripts, and style sheets. There can be only one head element in an HTML document.
  9. Hypertext
    - link that connect web pages to one another, either within a single website or between websites.
  10. HyperText Markup Language (HTML)
    - formatting language for displaying content over Internet. https://www.britannica.com/technology/HTML
  11. label
    - element that represents caption for an item in a user interface.
  12. legend
    - element that represents a caption for the content of its parent fieldset or a group of related form controls.
  13. link
    - HTML element that specifies relationships between the current document and an external resource. Most commonly used to link stylesheets, but is also used to establish site icons (both favicon style icons and icons for th home screen and apps on mobile device) among other things.
  14. media
    - attribute of link that specifies media type or allow to add query inside, This resource will then only be loaded if the media condition is true.
  15. preload
    - link attribute which indicates that the browser should preload this resource, together with as attribute indicating the specific class of content being fetched (new performance and security enhancement)
  16. Placeholder
    - attribute that defines the text displayed in a form control when the control has no value. Effective placeholder text includes a word or short phrase that hints at the expected data type, not an explanation or prompt. This attribute is supported by the following input types: text, search, url, tel, email, and password and by textarea element.
  17. rel
    - link element attribute that stands for relationship, and is one of the key features of link element, rel value denotes how the item being linked to is related to the containing document. Could be also used to indicate icon types.
  18. setInterval
    - method of the Window interface repeatedly calls a function or executes a code snippet, with a fixed time delay between each call.
  19. setTimeout
    - method of the Window interface sets a timer which executes a function or specified piece of code once the timer expires.
  20. Symbolic link
    - special computer file that refers to another file or directory by storing a path to it (also symlink or soft link)
